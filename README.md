# 🌍 Global Methane Emissions Dashboard

An interactive Streamlit dashboard analysing global methane emissions using World Bank data from 2000 to 2023.

---

## Live Dashboard
https://methane-dashboard-hqqjnpizurteeqvwnzcobz.streamlit.app/

---

## 📊 Project Overview
This project presents an interactive data visualisation dashboard that allows users to explore methane emissions across countries. Users can analyse trends, compare multiple countries, and identify the highest methane-emitting regions.

---

## ✨ Key Features
- Country-wise methane emission trends  
- Global methane emission analysis  
- Multi-country comparison  
- Top 10 emitting countries  
- Distribution of emissions  
- Heatmap visualisation  

---

## Dataset
- Source: World Bank Open Data  
- Link: https://data.worldbank.org/indicator/EN.ATM.METH.AG.KT.CE  

---

## 🛠 Technologies Used
- Python  
- Streamlit  
- Pandas  
- Plotly
